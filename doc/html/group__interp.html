Point interpolation on high-order element using Koornwinder polynomials.

The coefficient matrix for the element is found by multiplying the element node locations by the Koornwinder polynomial matrix from sqt_koornwinder_interp_matrix, or using a BLAS operation (here using the blaswrap wrapper) 

     al = 1.0 ; bt = 0.0 ;
     blaswrap_dgemm(FALSE, FALSE, nq, i3, nq, al, K, nq, xi, xstr, bt, ci, i3) ;
Parameters
ciinterpolation coefficients for element;
nqnumber of element nodes;
Nkorder of Koornwinder interpolation;
slocal coordinate for interpolation;
tlocal coordinate for interpolation;
xon exit contains interpolated point location;
non exit contains element normal at x;
Jon exit set to Jacobian at x;
dxif not NULL, on exit contains local derivatives , ;
workworkspace of at least 3*nq elements;
Returns
0 on success.
